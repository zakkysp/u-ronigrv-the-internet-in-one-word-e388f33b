One word for the whole internet, funniest and most fitting wins. This entry's word is **later** — the internet promised everything instantly and delivered a civilization of "I'll get to it later": watch-later queues, read-later lists, three hundred open tabs, unread messages, saved posts never revisited. The program writes that single word to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
